Q2.Explain the four pillars of OOP.

The four pillars of OOP are Abstraction, Encapsulation, Inheritance, and Polymorphism.

  1. Encapsulation: Encapsulation is the process of wrapping data and methods into a single unit called a class. It also protects data from direct access by using access modifiers.
    Example: Private variables and public getter/setter methods (e.g., bank account balance kept private).
  2. Inheritance: Inheritance is a process in which one class acquires the properties and methods of another class. It helps to reuse existing code and reduce code duplication.
    Example: A Dog class inherits from an Animal class — class Dog extends Animal {}
  3. Polymorphism: Polymorphism means one name with many forms. It allows the same method or object to perform different tasks in different situations.
    Example: Method overloading and method overriding.
  4. Abstraction: Abstraction is the process of hiding unnecessary implementation details and showing only the essential features of an object to the user.
    Example: Abstract classes and interfaces in Java (real life: ATM withdraw button hides the internal process).
Remember: E-I-P-A · Encapsulation = Data বাক্সে বন্ধ · Inheritance = code reuse · Polymorphism = One name, many forms · Abstraction = কী করে দেখায়, কীভাবে করে লুকায়

Q3.Define Abstract Class, Abstract Method, and Interface with example.

Abstract Class: An abstract class is a class that is declared with the abstract keyword. It cannot be used to create objects directly. It can contain both abstract and non-abstract methods.

abstract class Animal {
    abstract void sound();

    void eat() {
        System.out.println("Eating");
    }
}

Abstract Method: An abstract method is a method that has no body or implementation. It has only a method declaration, and its implementation is provided by the subclass.

abstract void sound();

Interface: An interface is a blueprint of a class that contains method declarations and constants. It is a contract that defines methods a class must implement. A class uses the implements keyword to implement an interface.

interface Animal {
    void sound();
}

class Dog implements Animal {
    public void sound() {
        System.out.println("Dog barks");
    }
}

Q4.What is Subclass Reference and Superclass Reference? Explain with example.

Subclass Reference: A subclass reference is a reference variable of a subclass type that is used to refer to an object of that subclass. It can access both parent and child members.

Dog d = new Dog();   // subclass reference

Dog = reference variable type · d = reference variable · new Dog() = object

Superclass Reference: A superclass reference is a reference variable of a superclass type that is used to refer to an object of its subclass. It can access only the members of the parent class.

Animal a = new Dog();   // superclass reference

Example

class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog is barking");
    }
}

class Main {
    public static void main(String[] args) {
        Dog d = new Dog();      // subclass reference
        d.eat();
        d.bark();

        Animal a = new Dog();   // superclass reference
        a.eat();
        // a.bark();   // Compile-time error
    }
}
Output
Animal is eating
Dog is barking
Animal is eating

Explanation: The subclass reference d can call both eat() and bark(). The superclass reference a can call only eat(), because bark() is not defined in Animal.

Remember: Child reference = Parent + Child সব · Parent reference = শুধু Parent-এর

Q8.Explain Method Overloading and Method Overriding with example.

1. Method Overloading

Definition: Method overloading is a process of creating multiple methods with the same name but different parameters in the same class. It allows a class to perform similar tasks in different ways.

class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    double add(double a, double b) {
        return a + b;
    }
}

class Main {
    public static void main(String[] args) {
        Calculator obj = new Calculator();
        System.out.println(obj.add(10, 20));
        System.out.println(obj.add(10, 20, 30));
        System.out.println(obj.add(5.5, 2.5));
    }
}
Output
30
60
8.0

Identification: Same method name + different parameters = Method Overloading.
Type: Compile-time Polymorphism (Static).

2. Method Overriding

Definition: Method overriding is a process where a child class provides its own implementation of a method that is already defined in its parent class. It allows the child class to change the behavior of the inherited method.

class Animal {
    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

class Main {
    public static void main(String[] args) {
        Dog obj = new Dog();
        obj.sound();
    }
}
Output
Dog barks

Identification: Same method name + same parameters + parent-child relationship = Method Overriding.
Type: Runtime Polymorphism (Dynamic).

Q10.Explain Constructor Execution Order with example.

Definition: Constructor execution order is the order in which constructors are executed when an object of a subclass is created. The parent class constructor executes first, followed by the child class constructor.

Execution Order: 1. Parent class constructor → 2. Child class constructor.

class A {
    A() {
        System.out.println("Class A Constructor");
    }
}

class B extends A {
    B() {
        super();
        System.out.println("Class B Constructor");
    }
}

class Main {
    public static void main(String[] args) {
        B obj = new B();
    }
}
Output
Class A Constructor
Class B Constructor

Explanation:

  • new B() creates an object of class B.
  • super() calls the parent class constructor (A).
  • After A finishes, the child constructor (B) executes.

Note: super() must be the first statement of the child constructor. Static blocks run once from Parent to Child; for every new object, the Parent's instance block and constructor run before the Child's.

Remember: আগে বাবা, পরে ছেলে

Q13.Write the uses of the super keyword with example.

Definition: The super keyword is used to refer to the parent class. In Java, it is used to access the variables, methods, and constructors of the immediate parent class.

There are three main uses of the super keyword:

  1. Access Parent Class Variable: Used to access a parent class variable when the parent and child have the same variable name. — super.speed;
  2. Call Parent Class Method: Used to call a parent class method that has been overridden in the child class. — super.display();
  3. Call Parent Class Constructor: Used to call the parent class constructor from the child class constructor. — super();
Complete Example
class Vehicle {
    int speed = 50;

    Vehicle() {
        System.out.println("Vehicle created");
    }

    void display() {
        System.out.println("Vehicle display");
    }
}

class Bike extends Vehicle {
    int speed = 100;

    Bike() {
        super();
        System.out.println("Bike created");
    }

    void display() {
        super.display();
        System.out.println("Bike speed: " + speed);
        System.out.println("Vehicle speed: " + super.speed);
    }
}

class Main {
    public static void main(String[] args) {
        Bike b = new Bike();
        b.display();
    }
}
Output
Vehicle created
Bike created
Vehicle display
Bike speed: 100
Vehicle speed: 50

Rules: super() must be the first statement of the child constructor. super cannot be used inside a static method. super can access only the immediate parent class members.

Q14.What is Multiple Inheritance and the Diamond Problem? How does Java solve it?

1. Multiple Inheritance

Definition: Multiple inheritance is a type of inheritance where one child class inherits from more than one parent class.

A       B
 \     /
    C
interface A {
    void showA();
}

interface B {
    void showB();
}

class C implements A, B {
    public void showA() {
        System.out.println("A method");
    }

    public void showB() {
        System.out.println("B method");
    }
}

Important: Java does not support multiple inheritance through classes. It supports multiple inheritance through interfaces.

2. Diamond Problem

Definition: The Diamond Problem occurs when a child class inherits the same method from two parent classes, creating confusion about which method should be executed.

      A
     / \
    B   C
     \ /
      D

Here, both B and C inherit from A and override the same method. If D inherits from both B and C, Java cannot decide which version of the method to execute.

How Java Solves It: Java avoids this problem by not allowing multiple inheritance through classes. When two interfaces have the same default method, the implementing class must override that method.

interface A {
    default void show() {
        System.out.println("A show");
    }
}

interface B {
    default void show() {
        System.out.println("B show");
    }
}

class C implements A, B {
    public void show() {
        A.super.show();
        B.super.show();
        System.out.println("C show");
    }
}

class Main {
    public static void main(String[] args) {
        new C().show();
    }
}
Output
A show
B show
C show
Remember: Multiple = One child, many parents · Diamond = Two parents, same method, confusion · Solution = Interfaces + Method Overriding

Q15.What is a Static Variable? Explain with example.

Definition: A static variable is a variable that is declared using the static keyword inside a class. It belongs to the class, not to individual objects. It is shared by all objects of that class, and only one copy of it is created.

Key Points:

  1. Declared using the static keyword.
  2. Only one copy is created for the entire class.
  3. Shared by all objects of the class.
  4. Can be accessed using ClassName.variable.
  5. Commonly used for college names and counters.
class Student {
    int id;
    String name;

    static String college = "ABC University";
    static int count = 0;

    Student(int id, String name) {
        this.id = id;
        this.name = name;
        count++;
    }

    void display() {
        System.out.println(id + " " + name + " " + college);
    }
}

class Main {
    public static void main(String[] args) {
        Student s1 = new Student(1, "Rahim");
        Student s2 = new Student(2, "Karim");

        s1.display();
        s2.display();

        Student.college = "XYZ University";

        s1.display();

        System.out.println("Total: " + Student.count);
    }
}
Output
1 Rahim ABC University
2 Karim ABC University
1 Rahim XYZ University
Total: 2

Explanation:

  • Both students share the same college variable.
  • Changing Student.college changes the shared value.
  • Every object increases the shared count by 1.
  • Therefore, the total count is 2.

Q16.Create an Employee class with calculateSalary(). Create two subclasses, Manager and Programmer, and override the method to calculate salaries according to their roles.

class Employee {
    double salary;

    Employee(double salary) {
        this.salary = salary;
    }

    double calculateSalary() {
        return salary;
    }
}

class Manager extends Employee {
    Manager(double salary) {
        super(salary);
    }

    @Override
    double calculateSalary() {
        return salary + (salary * 0.20);
    }
}

class Programmer extends Employee {
    Programmer(double salary) {
        super(salary);
    }

    @Override
    double calculateSalary() {
        return salary + (salary * 0.10);
    }
}

class Main {
    public static void main(String[] args) {
        Employee e1 = new Manager(50000);
        Employee e2 = new Programmer(50000);

        System.out.println("Manager Salary: " + e1.calculateSalary());
        System.out.println("Programmer Salary: " + e2.calculateSalary());
    }
}
Output
Manager Salary: 60000.0
Programmer Salary: 55000.0

Explanation:

  1. Manager receives a 20% bonus: 50,000 + 10,000 = 60,000.
  2. Programmer receives a 10% bonus: 50,000 + 5,000 = 55,000.
  3. Both classes override the calculateSalary() method.
  4. The actual object decides which method executes. This is Method Overriding and Runtime Polymorphism.
