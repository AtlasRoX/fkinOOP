# OOP Final Exam — Last Day Prep

A browser-based Java Object-Oriented Programming final-exam revision guide.

## What is included

- 18 exam-style questions with ready-to-write explanations
- Java examples covering classes, objects, inheritance, abstraction, interfaces, polymorphism, constructors, exceptions, and more
- Responsive question navigation with an automatically generated table of contents
- Syntax highlighting for Java code blocks
- Per-question **Learned** checkboxes with progress saved in the browser's local storage
- Light and dark themes that follow the system preference

## Open the guide

No build step or dependencies are required. Open [`OOP Final Exam – Last Day Prep.html`](./OOP%20Final%20Exam%20%E2%80%93%20Last%20Day%20Prep.html) directly in a modern browser.

The page loads Inter, Noto Sans Bengali, and JetBrains Mono from Google Fonts when an internet connection is available. The guide itself remains usable offline with fallback fonts.

## Notes

- Progress is stored locally in the browser under `oopDone`.
- Clearing the browser's site data resets the learned-question progress.
- The Java snippets are study examples and are not compiled by the page.
